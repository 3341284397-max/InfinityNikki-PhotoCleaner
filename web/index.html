给搭配师的本地小工具

游戏里删掉的截图，电脑上还在占地方

在《无限暖暖》里删掉相册照片后，X6Game\ScreenShot 里的原图不会跟着消失。 这个工具帮你把它们挑出来——照片不上传、不联网，全部在你的浏览器里完成。

1

选择游戏文件夹

选中 X6Game 这一层，浏览器会向你请求读取权限

2

自动比对

把本地截图和相册缓存对一遍，标出游戏里已删除的那些

3

一键移进待清理文件夹

勾好之后点「移动照片」，把它们挪到一边，删不删还是你说了算

首次使用会从这里建立一份「相册台账」，之后才能判断哪些是你在游戏里删掉的

想要一键移动、一键还原？用桌面版 Windows 免安装单文件，点一下就把截图挪进待清理文件夹 下载 exe GitHub 备用 · 百度网盘（1111）
没有服务器、没有上传、没有统计。断网也能用。

把照片挪到一边

浏览器不会把文件夹路径告诉网页，所以这一栏要你自己粘 —— 在资源管理器地址栏点一下就能复制。填了脚本放哪儿都能跑；不填也行，双击时它会让你把文件夹拖进窗口。
